# Prompt: Production Readiness Review

```text
Perform a production readiness review.

Do not deploy.

Check:
- Requirements coverage
- Architecture docs
- Test plan and test evidence
- CI/CD gates
- Security controls
- Secrets handling
- Observability: logs, metrics, traces, dashboards, synthetic checks
- SLO/SLI/error-budget evidence
- Monitoring and alerting with owners and runbooks
- Reliability and scalability evidence
- Capacity/load-test evidence or approved waiver
- Runbook
- Incident response
- Rollback plan
- Operational readiness gate
- Release checklist

Create or update:
- docs/release/production-readiness-review.md

Return:
- Go / No-Go
- P0 blockers
- P1 blockers
- Evidence
- Required remediation
```
