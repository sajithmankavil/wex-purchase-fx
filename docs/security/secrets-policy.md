# Secrets Policy

## Rules

- Never commit secrets.
- Never print secrets in logs.
- Use managed secret stores for deployed environments.
- Use local `.env` only for local development, never committed.
- Rotate secrets on suspected exposure.
- Use least privilege for service credentials.
