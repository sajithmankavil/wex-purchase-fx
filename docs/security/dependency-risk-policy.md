# Dependency Risk Policy

## Rules

- Prefer mature, maintained dependencies.
- Pin versions using lockfiles.
- Review licenses for production use.
- Run vulnerability scanning in CI.
- Do not add dependencies without documenting why.
- Remove unused dependencies.
