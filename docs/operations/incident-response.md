# Incident Response

## Severity Levels

| Severity | Definition | Response Target |
|---|---|---|
| SEV1 | Critical user/business impact | Immediate |
| SEV2 | Major degraded functionality | TBD |
| SEV3 | Minor degradation | TBD |

## Process

1. Detect
2. Triage
3. Mitigate
4. Communicate
5. Resolve
6. Postmortem

## Postmortem Template

- What happened
- Impact
- Timeline
- Root cause
- What went well
- What went poorly
- Action items
